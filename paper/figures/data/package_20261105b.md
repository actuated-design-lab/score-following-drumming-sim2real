### 1.2 組み立てモデルの手首角 RMSE（`pkg2_wrist_rmse.csv`）

Gen2 の sim（DR なし）に、10/05 の実機と同じ指令を開ループで流し、手首角を比べた（最初の 2 s を除く）。
- 入力の種類：measured = 実測の圧力をそのまま入れる（機構モデルだけの誤差）、model = Gen2 の圧力モデル＋通信の遅れ 8 ms（指令から角度まで通し）
- 「同定に不使用」の列が「はい」の行が独立した検証。ステップは手首の粘性を決めるのに使ったので独立ではない

| 動作 | 入力 | 同定に不使用 | RMSE [deg] | 平均ずれ（sim − 実機）[deg] | 遅れ [ms] | 振れ幅の比（sim ÷ 実機） |
|---|---|---|---|---|---|---|
| 正弦 | measured | はい | 5.89 | −1.68 | 0 | 1.08 |
| 正弦 | model | はい | 7.52 | −2.73 | +25 | 1.06 |
| ダブルストロークの再生 1 | measured | はい | 6.44 | −4.36 | +5 | 0.92 |
| ダブルストロークの再生 1 | model | はい | 7.44 | −4.52 | +20 | 0.85 |
| ステップ | measured | いいえ | 3.34 | −1.15 | −5 | 1.09 |
| ステップ | model | いいえ | 3.18 | −1.26 | +20 | 1.07 |
| GMD の再生 | measured / model | はい | **未**（WS） | | | |

- 遅れ：sim を時間方向にずらして RMSE が最小になるずれ。正 = sim が遅い
- **GMD の再生は 10/05 のログの Gen2 での再生がまだない**ので `run_1105_pkg.sh fidelity` で回す。あわせてダブルストローク 2 本目・準静的・拮抗も回す
- 10/05 の GMD の録音は元圧が下がっていた（JFPS で圧力の検証から外した）。measured の行は実測圧力を入れるので機構の検証として使えるが、model の行は元圧の低下の影響を受ける

出典：porcaro_2026 `scripts/tools/user0/jfps2026/check_gen2.sh`（replay_open_loop.py `--env_cfg Gen2`）→ `analysis/eval/compare_hys_modes.py` → `data/user0/jfps2026/replay/gen2_check/metrics.csv`。実機は jetson_project `data/user0/jfps2026/playback_20261005/`
