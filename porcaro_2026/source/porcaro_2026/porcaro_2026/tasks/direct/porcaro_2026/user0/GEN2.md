# Gen2 — 機構側を実測で作り直して凍結した学習用 sim（2026/10/29）

前の版の sim（設定クラス `Porcaro2026EnvCfg_Default` / `_DR`）を **Gen1** と呼ぶ。
Gen2 は機構側（力・ワイヤ・関節・質量）と圧力モデルを実測ベースに置き換え、合わせ込みの倍率を持たない設計値で凍結したもの。
Gen1 のクラスは再現用に残してある。観測・行動・報酬は Gen1 と同じ（観測 v2 は下の「(b) の学習のタスク」）。

| 設定クラス | 用途 |
|---|---|
| `Porcaro2026EnvCfg_Gen2` | 基準（DR なし）。検証・再生用 |
| `Porcaro2026EnvCfg_Gen2_DR` | DR あり。`_Gen2_B` の継承元 |
| `Porcaro2026EnvCfg_Gen2_B` / `_Gen2_B_ObsV1` | 学習に使ったタスク（`Porcaro-Gen2-B-user0` / `Porcaro-Gen2-B-obsv1-user0`） |

タスクの登録は `user0/__init__.py`。学習ログは `porcaro_rslrl_{lstm,mlp}_gen2/` に入る（`agents/rsl_rl_ppo_gen2_cfg.py`）。

## Gen1 で効いていなかったもの（2026/10/29 に判明）

Gen1 の環境は `_reset_idx` でコントローラの `reset_idx` を呼んでいなかった。そのため
- 圧力モデルの τ の倍率（`pam_tau_scale_range = (0.8, 1.2)`）は一度も抽選されず、全環境で範囲の中央（1.0）のままだった
- 圧力チャネルの状態（圧力・遅延バッファ）はエピソードをまたいで持ち越されていた

Gen1 のクラスは再現のため既定では呼ばないまま残し（`reset_controller_on_episode = False`）、Gen2 だけ呼ぶ。

### リズムのリセットが 2 回（Gen1 から）

`_reset_idx` は `rhythm_generator.reset` を 2 回呼んでいる。エピソードの長さ（16 拍）は 1 回目に引いた BPM から計算し、
実際に流れるリズムと観測の BPM は 2 回目に引いたもの。そのため、たとえば 160 BPM の長さ（6 s）で 60 BPM のリズム（最初の 4 s は休み）が流れたり、
60 BPM の長さ（16 s）で 160 BPM のリズム（6 s で終わり、残りは休み）が流れたりする。Gen1 の学習分布もこれを含む。
`rhythm_reset_once = True` で 2 回目を呼ばない（既定は False = Gen1 のまま）。`_Gen2_B` は True。

## (b) 周期的でない打撃列（`rhythm_mode = "random"`。既定は "grid"）

`rhythm_generator.set_random_mode`。エピソードの長さ（16 拍）、最初の 1 小節の休み、目標の力の波形、観測、報酬は grid と同じ。
- テンポ：エピソードごとに `rand_bpm_range` から連続値で一様に引き、エピソードの中では一定（拍の位相の観測と矛盾させない）
- 打撃：2 小節目の頭から、間隔を音価 `rand_note_beats`（16 分・8 分 3 連・8 分・付点 8 分・4 分・付点 4 分・2 分）から
  `rand_note_probs` で選んでつなぐ。確率 `rand_rest_prob` でその音符を休みにする。間隔が `rand_min_interval_s`（0.08 s）未満の音価は使わない
- カリキュラム（`rand_curriculum`）：レベル 0 はテンポ範囲の下 1/3・8 分より短い音価なし、レベル 1 は下 2/3・16 分なし、レベル 2 は全部
- 助走の固定（既定は無効）：`rand_lead_in_s ≥ 0` で最初の 1 小節の休みをやめ、最初の打撃をその時刻に置く。
  `rand_episode_beats` 拍ぶん並べ、エピソードは `rand_lead_in_s + rand_episode_beats 拍 + rand_tail_s`（既定 0.5 s、最後の打撃の報酬を収めるため）。
  評価の MIDI（最初の打を 2.0 s に置く）と、助走と拍の位相の関係が同じになる

## (b) の学習のタスク（2026-11-01）

`Porcaro2026EnvCfg_Gen2_B`（タスク `Porcaro-Gen2-B-user0`）が主、`Porcaro2026EnvCfg_Gen2_B_ObsV1`（`Porcaro-Gen2-B-obsv1-user0`）は観測だけ v1 にした予備。
機構側・DR は `Gen2_DR` のまま。値は cfg に固定し、コマンドラインの上書きは使わない（取り違えないため）。
- 分布：テンポ 60〜160 一様（エピソード中は一定）、音価の確率 16 分 0.45・3 連 0.076・8 分 0.183・付点 8 分 0.061・4 分 0.122・付点 4 分 0.061・2 分 0.047
  （16 分 0.28 では IOI < 120 ms が学習全体で 3.3 % しかなかったので上げた）、
  休み 0.15、最小間隔 0.08 s、助走 2.0 s ＋ 32 拍 ＋ 余白 0.5 s、`rhythm_reset_once = True`
- カリキュラム：iteration で固定（`curriculum_iters = (300, 750)`）。0〜299：テンポ 60〜93・8 分より短い音価なし／300〜749：60〜126・16 分なし／750〜：全部。
  レベルが効くのは、切り替えのあとに始まったエピソードから（32 拍・60 BPM のエピソードは約 14 iteration 続く）
- 打撃列の乱数：学習の seed で固定（`np.random.default_rng(cfg.seed)`）。検証用・評価用のホールドアウト列は、これと重ならない種で別に作る
- 観測 v2（`obs_version = "v2"`、1 フレーム 37 次元、frame stack 5 で 185）：`[q2, qd2, 前回指令3, BPM/180, 先読み25, 圧力3 / Pmax, 接触1]`。拍位相（sin/cos）はなし
  - 圧力：コントローラの `P_out`（ITV 出口の圧力のモデル、200 Hz の物理ステップの最後の値）に、エピソードごと・筋ごとのずれ（±0.01 MPa【仮】）と
    白色ノイズ（0.005 MPa【仮】）を足し、1 tick（20 ms）遅らせて入れる（`obs_sensor_delay_steps = 1`【仮】）
  - 接触のラッチフラグ：tick の区間（物理 4 ステップ）に k_t を掛けた力の大きさが 1 N 以上なら接触。1 tick 遅らせ、OR で溜め、
    tick (k − 1 + 2) の目標波形が 0.75 × 20 N 以上なら 0 に戻す（目標の時刻の 20 ms 前の区間からを、その目標の窓にする）。
    実機（jetson_project の `src/obs_v2.py`）は遅れを足さず、tick (k + 2) で戻す。200 Hz の全パケットの force_N の最大を見る
- 予備（v1）：分布は主と同じ、観測は Gen1 と同じ 35 次元
- 確認：`scripts/tools/user0/gen2/check_obs_v2.py`（観測の次元、分布の値、カリキュラムの境目、観測の並び、圧力の遅れ、接触フラグを参照実装と突き合わせる）
- 学習：`scripts/tools/user0/gen2/train_b.sh`

## 再生（検証用 sim と学習用 sim を同じにする）

```bash
python scripts/tools/user0/jfps2026/replay_open_loop.py --env_cfg Gen2 --pmodel cfg \
    --signal <指令の CSV> --no_drum --headless --out out/sim_tm_B_steps__gen2.csv
```

`--pmodel cfg` は環境の圧力モデル（Gen2 なら shaped＋通信の遅れ）をそのまま使う。`--pmodel measured --real_log ...` なら
実測圧力を入れて機構側だけを比べる（凍結の検証と同じ条件）。

## 凍結していないもの

- 打撃力：k_t（仮 1.6）、反発係数（物理材料 restitution 0.8、摩擦 0）、打面との接触。sim は跳ね返りの山が多い（実機 140 に対して sim 202）。
  学習（Gen2_DR）はロボット側の反発を DR で 0 にしているが、DR なしの再生（Gen2）は USD／既定の材料のまま。`replay_open_loop.py --print_materials` で実際の値を確かめられる
- 通信の遅れの値
- θt の DR の幅
- G の圧力が手首に効くか（10/29、G = 0 の保持で手首が 10/05 より 25° 高い）
